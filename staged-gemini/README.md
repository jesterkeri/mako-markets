# Staged Gemini components (NOT routed)

These components were generated by Gemini for the Phase 1 onboarding rebuild
(email signup, Magic.link, USDC, fiat onramp, Safe). They reference state
(Magic sessions, USDC `$` display, Monnify VAN, MoonPay, etc.) that does not
yet exist in the live app.

They live outside `src/` deliberately so:

1. Next.js won't route or type-check them as part of the main build.
2. No consumer in `src/` can accidentally import them and drag USDC/Magic copy
   into the v3 frontend before the Phase 1 USDC migration sweep lands.
3. The plan's hard rule "NO partial USDC migration" stays enforceable.

During Phase 1, components get moved into `src/` piece-by-piece alongside the
wagmi/Magic wiring they need. Anything still here at Phase 1 cutover has been
superseded or dropped.
